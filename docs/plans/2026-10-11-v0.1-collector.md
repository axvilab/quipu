# v0.1: collector and cache report

Status: open · 2026-10-11

Goal: `quipu cache` shows cache hit % per project and day from real transcripts.

1. Spike: read a few real transcripts (read-only), write down the fields we need (usage,
   cache_read/cache_creation tokens, model, cwd, version). Build synthetic fixtures from them.
2. `internal/claudecode`: discover profile config dirs; list transcripts; tolerant line parser.
3. `internal/store`: interface + DuckDB backend; switch Makefile to CGO.
4. `internal/collect`: `quipu daemon --once` converts new JSONL to Parquet.
5. `internal/analytics` + `quipu cache`: table by project/day.
6. Run on real data; decide whether to continue (see DESIGN §3).
