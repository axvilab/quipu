# Editor for instruction files

Status: done · 2026-10-11

## Goal

Fix what the advisor marks "manual" without leaving quipu: open the file, see what it costs per
session while typing, save. Saving goes through the same journal as Apply, so it is backed up,
listed under "Changes made by quipu" and can be undone.

## Scope

- Editable: files Claude Code loads for a known project or for the profile (CLAUDE.md, rules,
  skills, agents, commands, memory, imported files), and the user's CLAUDE.md even before it
  exists. Not files synced from claude.ai or installed by plugins: they are managed elsewhere and
  would be overwritten.
- API: `GET /api/file?path=` (content, version = content hash, tokens, whether it is sent in
  every session), `POST /api/file` (path, content, version; refused when the file changed since
  it was opened), `POST /api/tokens` (token estimate for the text being typed).
- UI: a wide side sheet with a plain textarea; token count and change against the saved file;
  Ctrl+S saves; closing with unsaved changes asks inline (no browser dialogs). Opened from a
  finding ("Edit file") and from the items on a project's Context tab. Screens refresh after a
  save, so a fixed finding disappears.
