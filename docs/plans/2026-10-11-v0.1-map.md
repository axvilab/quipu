# v0.1: project map

Status: done · 2026-10-11

Goal: `quipu map [path]` shows what Claude Code sends for a project: what is loaded into every
session, what only on demand, how many tokens each part weighs, and how that compares with the
measured start weight of real sessions.

1. [x] `internal/claudecode`: find instruction sources of a project, following the documented
   loading rules:
   - always: user `CLAUDE.md`, `CLAUDE.md` / `.claude/CLAUDE.md` / `CLAUDE.local.md` in the
     project and its parents, their `@imports` (up to 5 levels), rules without `paths:`,
     `MEMORY.md` (first 200 lines / 25 KB), name + description of every skill and agent
     (user, project, enabled plugins);
   - on demand: rules with `paths:`, skill and agent bodies, `CLAUDE.md` in subdirectories,
     other memory files.
2. [x] Token estimate per item (no tokenizer locally: approximate, marked with `≈`).
3. [x] Measured start weight from the store: prompt tokens of the first request of each main
   session (includes Claude Code's own system prompt and tools, which files cannot show).
4. [x] `quipu map [path]`: grouped output, heaviest first, totals per group.
5. [x] Run on real projects; note what the advisor (module 5) should flag.

Out of scope for now: MCP server tool lists (need `.claude.json`, read-only), plugin hooks,
output styles.

## Outcome

On real projects the files Claude Code loads in every session weigh ≈ 5–6K tokens, while the
measured first request is 40–48K. Most of the start weight is not in the user's files: Claude
Code's system prompt, tool definitions and MCP servers. Next for the map: list MCP tools.

Advisor candidates seen on real data:
- a large `@import` in CLAUDE.md is paid in every session (a 2.5K design doc here); a plain
  reference ("read docs/DESIGN.md before architectural changes") costs a few tokens;
- skills synced from claude.ai are listed in every project (≈ 2K here) although most are unused
  in code projects; `skillOverrides` or `syncClaudeAiSkills: false` turn them off;
- big subdirectory `CLAUDE.md` and memory topic files are on demand and fine.
